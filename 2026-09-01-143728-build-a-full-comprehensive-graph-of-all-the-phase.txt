     Per-phase substance already established (so the sub-pages are written, not 
     researched)

     - indexing — IndexingRunner, INDEXING_VERSION 1.0.0. Transient-mount retry
       → discovery (prune_indexing_excluded_walk_dirs) → fast-skip →
       content-fingerprint reuse → UUID adoption → compute_image_identity_hash
       (v1 full-file SHA-256 vs v2 largest-embedded-JPEG-preview, 3 candidate
       sources) → split-brain collision resolution between UNIQUE(file_path) and
       UNIQUE(image_hash, hash_version) → register/upsert → IPS. NEF-aware
       folder_id assignment.
     - metadata — MetadataRunner. UUID → embedded EXIF ImageUniqueID + XMP
       sidecar → XMP-first DB sync → thumbnails (512×512; failure is a hard IPS
       failed, error thumbnail_generation_failed) → IPS.
       Empty-scope-but-folder-non-empty is a deliberate hard fail.
     - scoring — 3-stage bounded-queue thread pipeline (prep_queue 50 → 
       scoring_queue 10 → result_queue 50), one ScoringWorker so GPU work is
       serialized, no tensor batching. Model-load circuit breaker (3 strikes).
       Four-stage score math: model-native → linear normalize() → percentile
       rescale with a soft floor [0,p02]→[0,0.15] → weighted fusion with
       re-normalization when models are missing → rating/label thresholds.
     - culling — SelectionRunner (preferred) vs ClusteringRunner (fallback,
       stacks only, no pick/reject). BurstUUID pre-grouping bypasses visual
       clustering; time-gap batching bounds comparison; MobileNetV2 features →
       AgglomerativeClustering(cosine, average, distance_threshold); embeddings
       persisted even for single-image batches (which is what makes their
       absence prove clustering never ran). Optional two-level (policy_version 
       2.0) and CLIP prompt-quality reject guard. Representative strategies
       score/centroid/balanced.
     - keywords — TaggingRunner. CLIP tagging (with persisted-embedding fast
       path) + optional BLIP captioning + optional accessibility text.
       Normalized schema keywords_dim/image_keywords; document the confidence
       (softmax, candidate-set dependent) vs relevance_weight
       (sigmoid(cos/0.18), set-size independent) distinction. Three distinct
       outcomes: done, skipped:caption_only_no_keywords, skipped:no tags 
       produced.
     - bird_species — BirdSpeciesRunner. YOLO bird-detect-v0 box → crop →
       BioCLIP-2 temperature-scaled softmax over "a photo of {name}, a bird 
       species". bbox sentinel taxonomy (NULL / {detected:false} / {error:…})
       with only detector_unavailable retryable. Detector-only
       scan_bird_bbox_only pass. Eligibility states:
       not_in_scope|complete|pending|exhausted|failed|skipped_other.
